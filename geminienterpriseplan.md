# Gemini Enterprise — FSI Pitch Plan

## What is Gemini Enterprise?

Gemini Enterprise is Google's **agentic AI platform for the workplace** — the "front door for AI at work."

| Edition | Price | Target |
|---|---|---|
| Business | $21/seat/month | Small teams, no IT setup needed |
| Standard/Plus | $30+/seat/month | Large orgs needing enterprise-grade IT controls |

**Core capabilities:**
- **Chat with Gemini** — search, analyze, generate content (text, image, video)
- **Agentic platform** — orchestrate agents to automate multi-step workflows; no-code agent builder for any user
- **Connectors** — Google Workspace, Microsoft 365, and other enterprise apps
- **Bring your own agents** — via Google's ADK or 3rd-party agents
- **Agent marketplace** — pre-built partner solutions
- **Security & governance** — Model Armor (screens malicious interactions), centralized agent visibility, data sovereignty controls
- **Gemini Code Assist** — developer coding agent (Standard tier)
- **Frontline edition** — designed for frontline/branch workers

## Why Gemini Enterprise for FSI (Governance Story)

- **Model Armor** — proactively screens for malicious/unsafe interactions (satisfies regulators)
- **Centralized agent visibility** — CISOs and CCOs can audit every agent interaction
- **Data sovereignty** — meets RBI/SEBI/GDPR data residency requirements
- **Bring your own agents** via ADK — banks aren't locked into a chatbot; they build an AI operating layer
- **Audit trail** — every Gemini interaction logged, supporting compliance oversight
